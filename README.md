Blender Addons - 
1) Absolute Texture - One click to activate and deactivate permanent fake texture. Through Properties side panel (N) , Tools, at the bottom Absolute Texture
2) Absolute Deselect J - Instead of shift double click, easily hoover mouse pointer over the object and press J to deselect
3) Absolute Colour - After rendering image with transparent background, instead of black, you can select any bg colour to save with it. At render page click image and save Jpeg with absolute colour
